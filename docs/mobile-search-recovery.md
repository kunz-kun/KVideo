# 手机搜索恢复修复

## 问题与范围

2026-10-27 报告：部分苹果手机搜索任意片名后显示“未找到相关内容”。截图是首页搜索空状态，尚未进入播放器。线上相同片名“小城良方”可以返回结果；无法取得故障手机或其 iOS 版本，因此未将原因归结为特定 iOS 缺陷。

代码确认存在以下问题：订阅同步只尝试一次，可能早于运行时订阅配置到达；订阅直连失败没有完整超时与 HTTP/解析失败回退；搜索响应提前结束被当成成功；网络错误和全部视频源失败均可能显示普通空结果。

## 修复

- 运行时订阅变化及网络恢复后重新同步；失败时可手动重试。无本地视频源时不受订阅冷却时间阻挡。并发挂载共享进行中的订阅下载，合并时使用最新设置。
- 订阅下载覆盖读取响应正文的超时；直连网络、HTTP 或解析失败时改用专用订阅接口。Cloudflare 的媒体代理保持关闭；新接口只接受站点已配置的订阅地址，并校验源列表 JSON 与 1 MB 大小上限，不转发视频。
- 搜索必须收到明确完成事件；正确处理跨数据块中文、CRLF 和末尾无换行事件，并释放读取器。
- 连接失败或超时后，最多用完整缓冲响应补查一次，避免依赖浏览器增量响应。结果按来源及视频 ID 去重。
- 当前搜索拥有独立的请求身份；取消后旧回调不能结束新搜索或覆盖缓存。
- 视频源未就绪时等待；失败时显示错误及重试按钮。确实无结果时保留原有提示。主站与高级模式均传递错误状态。

- `npm run build` 通过，包括旧浏览器客户端资源转译。
- Chromium 手机尺寸 393 × 852：延迟运行时配置与订阅后自动搜索；截断响应自动补查；持续失败时的错误及重试恢复；真实空结果。未发现该流程的页面脚本错误或横向溢出。
- 不以手机尺寸或 iPhone User-Agent 模拟作为真实 Safari/iOS 验证；上线后仍需由故障手机复测。
